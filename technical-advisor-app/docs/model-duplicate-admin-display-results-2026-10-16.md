# 模型副本、Admin 角色与身份显示修正结果

对应方案：`docs/superpowers/plans/2026-10-16-model-duplicate-admin-display.md`。

## 变更

- 模型“复制配置”改为 POST /api/advisor/models/{endpointId}/copy，服务端新增真实副本，保留连接、密钥、模型、向量维度和上下文容量，使用新 ID 与副本名称，不设为默认、不发厂商探测。前端刷新服务端列表，必要时定位末页；不再使用剪贴板，响应仅返回掩码。原 copy-config 接口保留兼容，但列表复制不再调用它。
- 已按用户明确要求修改本地数据库：确认 demo-admin 无智能体、会话、技能、工具、MCP、知识库资源后，在事务中删除账号及角色/偏好关联（登录会话随账号级联删除），将现有 admin 的 user_number 改为 1。未修改密码或其他业务内容。
- role-admin 允许编辑名称、标识、排序和菜单权限，仍禁止删除、停用；其他内置角色保护保持。权限管理入口不能移除，防止锁死管理员。权限只在首次创建系统角色时初始化，后续启动保留用户保存的菜单权限。
- 菜单权限入口移除图标。授权保存成功后重新获取当前身份，菜单、侧栏及按钮权限即时更新。
- 左下角身份区域优先显示去除首尾空白后的昵称，其次显示账号。使用已有身份订阅，修改本人昵称成功后同步更新。
