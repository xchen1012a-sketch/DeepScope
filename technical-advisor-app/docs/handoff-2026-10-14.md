## 五、关键决定（下一个人必须知道）

1. **MCP 服务编辑必须先握手再落库**：
   `PATCH /api/advisor/mcp-servers/{serverId}` 会先对目标端点执行 `mcp.list(endpoint)`。如果连不上（网络挂掉、命令不存在），返回 502 并保留原数据库配置，绝不产生破坏性的脏更新。
2. **Schema 工具绑定的第二条路**：
   导入时若传 `boundToolId`，将跳过 HTTP 连通性探测（无需填地址），直接检验目标 MCP 工具和服务的有效性与连通性，入库时直接设为 `origin=mcp` 并绑定 `mcpServerId`。
3. **未读列与辅助表保留**：
   `advisor_tool_change_requests`（幂等表）、`advisor_tool_definition_revisions`（版本历史表）、`provider_name`、`lifecycle_status`、`pending_json` 保持原样，后续开工对应项时直接接入，严禁删除。
4. **`If-Match` 乐观锁约定**：
   工具与 MCP 服务编辑均支持 `If-Match` 标头（也可从 body 的 `revision` 字段读取）。版本号不一致报 409 `revision_conflict`。
5. **部署密钥约束**：
   凭据加密依赖 `ADVISOR_TOOL_CREDENTIAL_KEY`（Base64 编码的 32 字节密钥）。本地测试用例中统一注入测试 Fake 密钥。

## 八、避坑指南

1. **Spotless 格式强制**：改完 Java 文件后，运行门禁前务必先执行 `mvn -T1 -pl technical-advisor-app/backend spotless:apply`，否则 `spotless:check` 必挂。
2. **Spring 依赖注入**：新增依赖 `ObjectMapper` 的 Bean 时，参数名必须使用 `advisorObjectMapper`，避免注入歧义。
3. **i18n 中英文词典强一致**：改动或新增错误码时，必须同步更新 `locales/en/app.json` 与 `locales/zh-CN/app.json`。
4. **H2 测试配置**：所有新加的 H2 测试 URL 必须带 `DB_CLOSE_DELAY=-1`。
5. **前端语法限制**：前端 target 是 ES2020，禁止使用 `.at()` 等较新特性。
