本文适用于独立应用 `technical-advisor-app/backend`，不涉及已移除的平台服务。

智能体创建页的“描述需求，AI 帮你生成”为可选辅助输入，只在需要 AI 生成配置时填写。手动填写名称和工作要求后，无需用途也可创建；名称和工作要求仍须通过既有校验。自由模式自动选择依据智能体名称和简介，不读取此辅助描述。

新建智能体时，临时输入不会自动创建侧栏草稿；主动生成、试运行、创建或离开时选择保存，才写入服务端。全部删空后不会保存空草稿，也不提示存在未保存内容。已保存草稿继续自动保存，离开页面保留既有保存/放弃选择。

知识库主列表高度受可用窗口限制，搜索栏与分页保持可见，列表内容在表格内部滚动，表头固定；横向滚动和服务端分页保留。

## PDF 知识库解析与来源

向量化使用所有文档共享的有界并发池，默认最多 3 个请求（`ADVISOR_EMBEDDING_WORKERS`，1—8），单条兼容请求不会被误当作多模态批处理。文档显示“已向量化 x/y 个片段”；内部保存成功向量的检查点，只复用同文件、模型、维度及内容/来源的结果。失败不发布半成品，完整发布事务成功后清理内部检查点。短正文按页和标题边界合并，表格/图片解释独立，引用保留每个原始块的区域。

PDF 解析最多 2 个同时在途调用。整页遇到适用的超时/截断/格式失败时，可在校正 PDF 声明旋转后沿中部连续空白带进行一次两区识别，再把坐标映射回原物理页；不递归分区、不强切文字或表格，任一区不完整仍整篇失败。无安全分隔、鉴权/限流或取消均不盲目增加分区请求。解析及向量化阶段独立记录耗时和复用量。

个人中心的“思考过程”只控制思考文本是否展示。关闭后隐藏历史及实时思考文本，原始记录仍保留，再打开即可查看；不改变模型菜单的 Think 开关、推理程度或下一轮请求参数。实际是否开启模型思考仍由模型菜单决定。最终回答与工具执行不受展示偏好影响。

知识库文档统一提供“查看内容”。PDF 延用原页和解析结果对照；Markdown、HTML、DOCX、TXT 使用固定高度、内部滚动的弹窗，可切换格式化/原始文本，以及服务端分页的“入库片段”。DOCX 展示提取后的正文与表格，不模拟 Word 原版式和页码。TXT 保留换行；HTML 仅渲染安全标签，不执行脚本、不复制原始事件/链接属性；Markdown 预览保留原文引用标记，图片只显示说明、不自动请求外部资源。预览不调用模型、不重新入库，受现有可见权限控制；正文超过 1MiB 时提示无法预览。入库片段为空时明确显示暂无已发布内容。

内容完整性与定位备注分开校验：明确的坐标估算不阻止入库，无效区域坐标降级为仅物理页定位；内容缺失、无法辨认和未知警告仍阻止整篇发布。模型可返回列头/行数组，由程序校验列数并生成表格，不补猜空单元格。JSON/字段错误最多从原页重新请求一次；网络错误不叠加格式修正。只有确认供应商支持时才开启 `ADVISOR_PDF_JSON_OUTPUT=true`，默认关闭，不能根据模型名称推断兼容性。

“重新处理”内部可复用同文件、同解析协议、同模型配置的成功页，仅再次解析未完成页；配置变化会使缓存失效，保存页及发布前均检查配置一致性。最终仍整篇原子发布，失败保留旧完整版本。页面错误包含脱敏类别；后台日志包含文档、处理编号、页码、模型、请求编号及耗时，不记录模型响应正文。日志默认保存到 `${advisor.data-dir}/logs/backend.log`，按 10MB 滚动，历史最多 7 天、归档总量最多 70MB。

收起的检索正文也使用紧凑 Markdown 格式化：标题、段落和表格保留结构，段距收紧，预览高度最多 7rem，超出部分点击结果标题展开查看。关键词只在解析后的文字中高亮，不破坏表格语法；原始片段不会被改写。

检索测试输入关键词、编号或待查内容描述，按钮为“检索”，结果统计召回片段数与来源文档数，不生成最终答案。每条默认显示序号、文件名、来源、排名分和最多三行摘要，点击标题展开/收起，一次只展开一条；不提供全部展开/收起、独立展开按钮和片段复制。展开正文有高度限制与内部滚动，正常渲染 Markdown 表格，原始文本切换收进展开区。新查询成功后重置展开状态。非 PDF 无物理页码时显示“文档片段”，不虚构页码或章节。PDF 预览保留格式化/原文切换、块定位与原页高亮。这些展示调整不修改已入库片段，不重新调用模型，也不能纠正模型本身的错列或漏值。

PDF 按物理页解析、保存文字块与来源区域。扫描、图文与复杂布局页由显式配置的视觉模型处理；任一必需页面失败或内容不完整，整篇失败，不发布半成品。真正空白页不算失败。旧文档需主动重新处理后才获得页码。

管理员在现有模型配置抽屉勾选“用于知识库 PDF 解析”，保存时会发送随机数字测试图片，验证识别能力后才指定。该角色同时只有一个模型，更换后动态生效，不改变默认聊天模型或向量模型。未在界面指定时可回退 `ADVISOR_PDF_VISION_ENDPOINT_ID` 环境配置；不会自动使用默认聊天模型。可选 `ADVISOR_PDF_RERANK_ENDPOINT_ID` 启用模型重排；未配置时按关键词与向量候选 RRF 融合排序。中文使用字串/双字匹配，编号保留；排名分不是相似度百分比，原相似度阈值只约束向量候选。关键词检索当前在所选库结构切片范围内扫描，大规模数据需另行评估索引性能。

文档列表的“查看页面”提供原页/解析结果对照、定位高亮与后端分页；统一通过“重新处理”重跑整篇，取消逐页重试和单独失败重试入口。列表显示排队、解析、向量化、入库阶段。命中测试与回答引用可以定位物理页。页面预览显示实际解析/复核模型名，未配置则禁用复核并提示配置。模型转录及图表解释保留标记，需要人工核对；只有点击“模型复核本页”才发送当前页和问题。查看/检索权限允许页面复核，编辑权限控制整篇重新处理。

默认最多 300 页、页图最长边 2000 像素，可分别通过 `ADVISOR_PDF_MAX_PAGES`、`ADVISOR_PDF_MAX_IMAGE_EDGE` 调整。后台默认 2 个工作线程与 32 个排队位置，可通过 `ADVISOR_KNOWLEDGE_WORKERS`、`ADVISOR_KNOWLEDGE_QUEUE_CAPACITY` 配置；文档总期限默认 20 分钟，由 `ADVISOR_KNOWLEDGE_TIMEOUT_MINUTES` 配置，含排队时间。向量 HTTP 单次最多 25 秒、总预算 60 秒、瞬态错误最多退避重试两次；PDF 视觉请求单次最多 45 秒、总预算 90 秒、最多退避重试一次。接收时限制响应为 1 MiB，视觉正文另限制 256 KiB；取消/超时会取消真实网络请求。空闲线程 60 秒回收，服务关闭统一清理。向量表创建、向量替换、结构切片、来源快照、维度和成功状态在同一 PostgreSQL 短事务提交，网络调用在事务外；重新处理失败保留旧完整版本。未接入真实视觉模型和代表性 PDF 样本实测前，不承诺识别准确率。跨页表格不猜测合并，不提供通用跨表求和。

首次启动后端时，通过 `ADVISOR_ADMIN_USERNAME` 和 `ADVISOR_ADMIN_PASSWORD` 指定管理员凭据。源码没有内置密码或默认密码；后续启动不会覆盖已有账号的密码。账号创建后，可移除这两个引导环境变量。

应用将账号与登录会话保存在配置的 PostgreSQL 数据库中。密码采用独立随机盐的哈希存储，登录令牌仅保存摘要。重启时需保留数据库及 `advisor.data-dir` 下的工作区和运行历史。

打开前端 `/login` 页面登录。`POST /api/auth/login` 接收凭据；`/api/auth/me` 和 `/api/v1/me/scope` 返回真实身份与单空间信息。登录会话默认有效 12 小时，可通过 `advisor.auth.session-ttl` 调整。退出登录时，`POST /api/auth/logout` 撤销当前令牌。

`agentscope.admin.base-path`（默认 `/v1/admin`）下的框架管理接口需要管理员 bearer 令牌；AG-UI 对话入口也需要登录，并检查智能体可见性、会话归属与锁定对象。本轮最小登录不包含注册、用户管理或旧平台业务接口迁移。

## 智能体管理

在 `/agent` 使用左侧智能体列表和右侧详情。点击列表项即可原地查看与修改；新建和未完成项继续使用创建流程。内置智能体所有人可见，仅管理员可编辑；个人智能体仅创建者与管理员可见可编辑。复制只复制定义工作区，不复制用户记忆或会话历史。管理员编辑的内置信息在重启后保留，个人智能体改名仍使用原会话历史。

详情顶部平铺工作要求、工具、技能、资料与子智能体页签，默认显示工作要求，仅挂载当前页签内容。名称和简介可原地编辑，修改后出现保存按钮；无编辑权限时只读。“开始对话”新建锁定该智能体的会话，复制与删除收进“更多”。文件编辑限于 `AGENTS.md`、`tools.json`、`skills/`、`subagents/` 与 `knowledge/`，运行数据不通过该编辑器暴露。子智能体说明使用框架既有 Markdown 与 YAML 定义格式。工具、技能、知识库三个能力页签（创建页的「高级能力配置」同）复用同一套列表组件：标准表头、勾选列与服务端分页，搜索在点击搜索或回车后提交；工具栏右侧显示已选用计数，列表下方保留保存按钮与保存结果提示。

产品身份固定为 DeepScope，并且每个智能体的定义文件会真正生效：装配时系统读出该智能体的 `AGENTS.md` 正文作为系统提示（本应用关闭了工作区上下文，这一步由上层显式完成），并在这段正文**之后**追加产品身份规则——所以 `AGENTS.md` 可以随时动态调整，但它的正文压不掉产品身份。被问“你是谁”时第一句必须回答“我是 DeepScope”，之后才可以补充自己的职责名称，不得自称“技术助手”“技术助理”“技术支持”或其它产品名；`AGENTS.md` 顶部另有一行系统维护的身份说明（幂等补齐，不改用户已写的正文）。AI 起草行为文档与子智能体定义时同样受这条约束；自由模式的基础对话也带同一身份。

新建子智能体从空白开始，不预填名称与模板。定义内容可用「AI 补齐」：填了名称才可用，旁边常驻提示说明会把名称与当前填写的内容发送给已配置的对话模型、仅用于生成本次定义；定义内容非空时先确认「覆盖生成」再整段替换，生成失败保留原内容并提示检查模型设置。

输入框底部、模型选择旁提供智能体选择器，新建会话和会话中均可使用。选择具体智能体后，本轮使用其运行时和已挂载能力，不自动改用其他智能体；选择自由模式才解除绑定，每条消息按现有路由分派，没有可见智能体时使用无工具的基础对话。

选择卡片按当前页真实数量自动收短，最高340px且不超过可用视口，每页最多5个智能体，名称12px、职责摘要11px。不提供左右分页按钮：滚轮下/上滑请求后端下一/上一页，回翻同样重新查询；触屏滑动及PageUp/PageDown也可请求翻页。关键词输入防抖200ms后由后端按权限过滤、搜索并分页，前端不下载完整清单做搜索。加载失败可重试，失效选择显示不可用而不静默转自由模式。

会话执行中可以修改下一条消息使用的智能体，当前执行不变；提交时把选择保存进该消息及排队快照，失败重试保留该次选择。工具确认恢复仍使用原运行时，切换需等当前执行/确认结束后在下一轮路由时生效。跨标签页直接改绑定也需取得现有运行时的空闲线程保护，否则返回409。会话记录继续保留，新智能体不会因历史文字获得其他智能体的工具权限。

欢迎页输入区从104px收紧到72px，宽度使用max-w-2xl，长文本继续自动增高到200px后内部滚动。选择器使用名称与锁定图标表达状态，不显示额外限制文案。

锁定会话中的子智能体提案进入等待确认状态。批准前可修改草稿；批准后写入独立定义文件，下一轮可派发，无需重启。内置智能体仅管理员可批准落盘，普通访客可拒绝。自由会话不允许提案；同名提案按提交先后裁决，重复裁决返回冲突。

切换智能体、页签或浏览器后退/前进时，有未保存修改会提示保存并切换、放弃修改或留在原处；保存失败保留编辑。刷新或关闭页面使用浏览器原生未保存提示。列表支持搜索，选中项使用浅紫色；加载失败可在对应区域重试。窄屏先展示列表，选中后显示详情，提供返回列表按钮。

## 侧边栏

侧边栏展开宽度为 248px，收起后为 64px 图标栏。桌面导航统一为 40px 行高、14px 文字和 18px 图标，触控设备适当增大操作区域。近期会话使用单行标题，时间与智能体信息放在悬停提示里，运行或等待状态仍保留。会话的“更多”菜单打开已有的重命名或删除确认。

侧栏使用固定布局，仅近期会话占用剩余高度并滚动；滚动时显示细滚动条，停止后自动隐藏。工作空间与设置采用互斥展开的分组，直接显示有权限的导航，不设置搜索框。模型设置和权限管理仍留在设置分组，退出登录收进账号菜单。紧凑图标导航、移动导航和语言切换保持可用。

矮屏使用更紧凑的导航间距，展开菜单提供限高内部滚动兜底，并隐藏额外滚动条，防止底部入口被裁切。

工作空间与近期会话之间保留间距。展开后将分组标题和内容一起放进独立白底、浅灰细边框与轻阴影的容器，设置分组同样处理；折叠和展开均不显示搜索框。

## 会话页

新建页和具体会话的文字草稿在当前标签页临时保存，按账号和会话隔离；刷新后回填，不自动发送，图片和附件不回填。消息保存成功后清除对应文字，失败保留；延迟回执不覆盖后来输入或重新打开页面后的新草稿。退出登录清理本应用临时草稿。

执行侧栏的“子智能体”页签以右上角数量角标展示已有子智能体，数量为 0 时隐藏。

会话页使用统一背景和一行标题，主对话通过留白区分回合，访客消息使用紫色浅底气泡。运行中的实际思考增量就地展示，历史分析记录点击后就地展开；工具调用在执行位置显示简短记录。最终回复使用连续正文，不增加交付物阶段或无实际位置的归档声明。

通过标题栏图标显示或隐藏执行侧栏。拖动左边界可调宽，边界获得焦点后也可用左右方向键调整；侧栏内不再设置关闭叉号。“轨迹”和“子智能体”沿用现有页签、记录定位和只读详情，开关侧栏不丢失输入草稿。

新建页与会话内共用同一个输入组件，所有状态的提示均为“与 DeepScope 协作”。首页按上海时间显示问候，优先显示昵称，空昵称回退账号；问候与输入区间隔约 32px，欢迎页输入区域拓宽、最小高度 104px，普通会话保持紧凑。草稿不再另建预览卡。新建和执行中均可展开斜杠菜单；运行中暂不能清空或压缩。代码块常驻图标复制入口；用户消息悬浮或键盘聚焦后在同一行显示复制图标与真实发送时间，按钮名称保留在悬停提示及无障碍标签中。

主会话标题与侧栏近期会话共享同一份名称缓存，由会话列表统一刷新；收起侧栏也不会使主标题停止同步。

输入区默认单行，收紧上下内边距，保留附件、模型菜单和紫色发送按钮。模型菜单逐行展示已配置模型，当前模型右侧打勾；菜单底部的 Think 滑动开关控制下一轮是否开启深度思考，开启时入口显示 Think。开关下方提供「推理程度」单行分段滑块，共五档（低、中、高、极高、Max），选中块随点击滑动，仅 Think 开启时可用，入口同步显示当前档位；选择通过账号偏好与浏览器缓存持久化，默认「高」。新建会话入口也使用相同菜单。模型设置权限与既有接口一致；无权限时仍显示运行数据回报的模型名，可以切换 Think 和选择档位。运行期间禁止切换模型和 Think；切换尚未确认时，按钮发送与 Enter 发送都暂时禁用。模型切换失败时保留当前模型并显示错误。

回合数、步数、耗时、首 token、输出速率和缓存统计收在点击“用量详情”后原地浮出的气泡弹窗里，关闭后不会改变页面高度，计算仍来自真实采样，无采样不参与平均。上下文环仅在用量与模型窗口都已知时出现，点击后也使用气泡弹窗，面板中的系统提示、工具、消息三行拆分仍为估算。

## 动态上下文容量

输入区的紧凑上下文入口使用 K/M 显示剩余 token，气泡弹窗显示已用、剩余和总量。容量跟随模型设置里当前启用的接入端；YAML 中的模型仅在没有已保存当前模型时作为回退。容量未获取时显示待获取，不把安全预算伪装成真实模型上限。

应用从已配置接入端的 `GET /models` 响应读取当前模型的 `context_window`（或兼容的 `context_length`）并保存。启动、模型成功添加/启用，以及当前模型尚未保存容量时会执行发现。接入端元数据优先于 SDK 的已知模型能力目录；发现失败保留之前的已知容量，未知模型仍使用框架的保守预算。

每次模型调用固定同一个模型快照，用于输入预算、生成和用量回报；修改全局模型选择不会把正在进行的调用标成新模型。历史压缩按 token 预算执行，保留输出与摘要所需空间，不再仅因为到达 50 条消息就提前压缩。

更新后需重启后端，自动执行幂等的 `context_window` 加列并发现当前保存的接入端能力。支持 1M 的接入端随后使用其声明窗口，应用不会将所有模型强制设为 1M，也不会发起付费的百万 token 探测。

## 基础对话降级

自由模式没有可见智能体时，路由使用当前配置模型进行基础对话。保留对话历史、流式输出、Think、用量统计和上下文预算；不使用工具、知识库或子智能体，不自动创建智能体配置。

锁定智能体不可用时，访客选择继续基础对话或在当前会话选择一个可见智能体。不存在或无权访问的会话仍返回404。失败重试复用已保存的访客消息，不重复落库。更新应用后重启后端，基础对话入口才会注册生效。

## 随对话展示思考与工具调用

新回复按实际顺序展示说明文字、思考阶段与工具调用。正常结束并确认最终正文后，中间过程整体折叠，最终正文保留在外面。入口显示真实耗时，统计服务端运行开始到最终正文首个增量，不包含最终正文输出与保存等待时间。调用失败不额外叠加汇总提示或计数，实际状态和错误仍可在具体详情中查看。

正常保存与断连兜底保留顺序及已有真实时间，刷新后恢复同一耗时。停止、错误、挂起或最终正文无法确认时保持过程展开；缺少时间的旧记录只显示查看过程，不显示0秒，也不推测缺失的分段位置。手动展开不会因记录更新而重置，执行时间线定位会先展开对应回合再高亮。

达到执行轮次上限但已生成可核对的总结时，过程也可收起，并始终显示“已达到执行轮次上限”。模型没有输出中间说明时，调用组上方根据真实工具动作显示操作说明。旧记录没有保留最终正文起点时，若有真实运行起止时间则明确标为“总用时”，不把它当作处理阶段耗时。

执行中，连续2条及以上的工具调用或派发记录默认收成一个批次，显示操作数量和执行中状态，点击可展开。说明文字、思考或需要用户处理的卡片会分隔批次；单条操作直接显示。结果更新、批次增长及整轮过程开合后保留批次展开选择，时间线定位会展开对应批次。

主行使用可读动作和简短目标，不直接展示shell命令、绝对目录或参数JSON。工具详情仍使用执行过程面板，分析记录改为当前位置展开。模型说明和正文深灰，工具、分析及自动动作说明浅灰。实际返回或等待状态优先，命令、参数和原始返回收在“技术详情”。派发回执不等于子任务完成，进程退出码与真实状态如实保留，不推断“全部通过”。

当前步骤或批次使用灰色文字流光和轻量活动点，不添加下划线；同一轮保留一个主要律动焦点，展开批次内单行静态。完成、失败、停止或等待用户处理时停止律动，并尊重系统“减少动态效果”。运行思考默认收起，只占“正在分析 · 当前思考”一行：新行滚入预览，长行随新增文字横向滚动。点击后才在固定240px高的窗口内查看完整思考，底部跟随更新，上翻后停止跟随，回到底部恢复。手动开合选择跨新增量与完成保持，历史分析默认收起。工具详情关闭后恢复原步骤焦点。

上下文圆环视觉为18px，保留32px操作区与原用量气泡。输入框自动增高到200px后内部滚动，在顶部或底部滚轮不带动外层对话；Ctrl/Meta滚轮缩放及Enter、Shift+Enter、中文输入法行为保留。

最终回答直接输出正文，不要求调用旧交付工具。已有智能体的工作区文件不被覆盖，应用运行约束仅修正内部汇报格式；旧工具注册保留以恢复待处理调用，但结果转普通正文，不新建交付归档。历史交付记录的唯一结论、建议和真实来源链接保留，纯元信息隐藏，同轮完整段落重复才去重。

内部事实标记不再要求模型生成，来源和结论仍保留。正文和子任务视图隐藏明确引用标记及已知内部编号前缀，代码、真实链接、路径与型号原文不被全局替换。子任务以名称、目标、当前动作和真实状态展示；只对正在查看的活跃任务所属分页补齐持久化进度，完成、返回或卸载后停止刷新，旧快照不能覆盖终态和新内容。

## 结构化追问卡片

需要补充信息时，问题卡片直接占用底部输入区，宽度与普通输入区一致；待回答期间隐藏普通输入框。选项前使用圆形数字编号，“其他”排最后并接续编号。单选点击即提交；多选选择后确认；“其他”及无选项问题在卡片内填写答案。卡片可折叠，消息区滚动不会将其卷走；运行收尾或提交期间禁用回答操作，运行尚未结束时保留停止入口。

标题单独使用动态短标题字段，建议 6–18 个中文字、最多 40 字符且单行，不复述用户原话、不写自述或枚举选项。必要说明和选项分别展示，长说明默认收进“问题说明”。旧记录按原问题首句生成有限长度的展示标题，原文完整保留，历史数据不重写。

提交失败保留选择和文字，可在卡片内重试。回答保存成功后卡片退出并恢复普通输入区，原有草稿和附件保留，聊天记录保留问题与答案。刷新后恢复未答卡片，已回答的问题不会再次出现。回答已保存但尚未产生执行内容时，可点击“继续处理”，沿用已保存答案而不重复发送访客消息。继续前检查服务端运行状态，避免重复启动已有执行；不会自动替用户选择或超时提交。

卡片通过现有输入组件的替换区域展示，共享队列仍可查看及取消；追问期间暂不能从队列直接发送，避免绕过待回答问题。

卡片追问期间隐藏智能体切换入口，卡片退出后随普通输入区恢复。中文问题的卡片系统提示显示中文。模型生成的 Other/其他选项与系统“其他”入口合并；点击后聚焦文字输入框，填写非空答案并确认后才提交。多选中勾选“其他”同样必须填写文字，不能只提交“其他”这个选项。

旧版文字追问与建议选项按原内容兼容展示。问题和回答在服务端关联、校验和去重；附件回答保留原附件上下文，刷新后继续使用同一份输入。此机制采用回答后开启下一轮处理，不会暂停某个工具线程等待用户。

## Think开关与首输出

关闭Think后，新回合不显示或保存思考片段，空思考生命周期标记不会被显示为“已思考”。所选推理程度档位仅在 Think 开启时随每轮运行传递；Think 关闭时档位被忽略，沿用原有的低强度。未知档位回退为「高」。DeepSeek请求明确关闭模型的thinking模式，不仅是降低推理强度或隐藏返回文本；历史回复中已存在的真实思考保留。

只有一个可见智能体时直接选派，多个候选仍逐轮选派。后端记录模型首个可见输出的耗时，不记录消息正文，便于区分供应商等待与应用准备。这项计时不承诺供应商的响应速度。

## 过程行与长内容

思考、工具和工具组使用统一轻量行：运行中显示紫色活动指示，文字保持黑灰；完成后为静态图标。分析入口使用“正在分析 / 分析记录”，点击就地展开真实内容，不为单次调用重复添加失败说明。

工具记录显示实际动作和简短对象，关键词、范围、命令及工作目录保留在技术详情。运行、完成和失败使用对应动作文案；记录来自真实调用，不把命令结束自动描述为测试通过。

连续工具按动作批次折叠，保留操作数量和实际顺序，失败记录仍在批次详情中。用户展开选择在更新和完成后保留，时间线定位会展开对应记录。

思考内容展开后在固定高度的窗口内连续滚动，运行中与完成后均不分段翻页，保留完整内容。参数和工具结果仍按每段约12000个字符查看，使用上一段/下一段切换；流式更新保留当前段，文本变短时页码自动调整。加载动画遵守系统减少动态效果设置；耗时计时在页面隐藏时暂停，任务结束或组件卸载后释放计时器与监听。

## 智能体创建流与隔离沙箱

新建主智能体采用用途优先的单页流程（`/agent/new` 与 `/agent/creation/:draftId`），未发布的配置保存在专用草稿存储中，与正式智能体、正式工作区完全物理隔离。

- **静默自动保存**：编辑过程中输入暂停 800ms 自动发起草稿保存，具备版本并发防护；未完成草稿可在智能体列表的“进行中的草稿”中继续编辑或清理。
- **AI 规划建议**：根据任务用途异步生成建议名称、简介和工作要求，支持一键应用或放弃，失败时不冲掉用户已有输入。
- **隔离试聊沙箱**：可在侧边栏发起沙箱试聊，试聊会话仅存储于独立的沙箱测试表，不向正式会话库与时间线写入任何数据，草稿变更时自动提示配置更新。
- **一键原子发布**：点击“创建并开始使用”后自动刷盘、核验配置合法性，并通过预分配标识与暂存物化执行原子发布，成功后直接进入正式对话。

## 会话运行与恢复

同一个会话同时只接受一次运行。重复发送和不符合权限的请求不会自动停止已有任务；停止请求只作用于对应运行。停止期间仍保留会话占位，旧任务的初始化与清理不能中断新任务。

工具需要确认时，独立卡片显示实际工具与输入，逐项选择允许或拒绝后统一提交；取消等待不会被当成允许。刷新后从服务端恢复尚未解决的确认，正在恢复中的旧确认不会再次开放。确认状态无法核验时不能继续批准。

刷新或短暂断网不会停止服务端任务。页面恢复时读取运行状态与已保存过程，不重发原问题；脱离实时流后仅在执行中持续查询。主动停止仍中断原任务。正常完成并保存、对账后才自动发送下一条排队消息；停止、失败、达到上限或等待确认时保留队列。断流先核对服务端状态，再决定是否显示失败。

手动压缩不设消息数或 token 门槛，空上下文无内容可压缩。自动压缩阈值为 800,000 tokens，小窗口模型仍优先遵循框架现有安全预算。断线与压缩配置需要后端重启后生效。

已启用原生会话日志的对话通过框架日志恢复实际上下文并保存压缩摘要；旧状态文件为空不会再导致原生历史被误判为空。旧状态模式继续走原有状态存储，压缩不会删除页面聊天记录。

详情读取不再触发任务结束或兜底保存。同一运行的客户端提交与服务端兜底按运行身份去重；内容冲突会报错。清空上下文会清理该会话实际使用过的智能体原生状态，运行中、等待确认或仍有待保存内容时拒绝清空；清理失败保留历史并显示失败。

文件工具返回的失败状态直接用于过程展示，文件内容以“Error:”开头不代表失败。过程定位按稳定条目标识匹配，子任务结束状态不被旧运行态覆盖。

## 工具与 MCP 生命周期管理

个人中心仅保留资料、安全、偏好与会话；移除“我的资源”及其凭据配置表，原地址回到资料页。资源仍从工作空间管理入口访问，工具认证设置不变。

AI 智能填入按钮采用纯文字，生成中锁定输入并显示状态文字。MCP 发现时将 SDK JsonSchema 序列化为标准 JSON，避免保存成 `JsonSchema[...]`。已有这类异常记录在 AI 填参和测试前，从同用户已接入的 MCP 读取真实参数定义；此恢复只读元数据，不执行工具、不改数据库或跳过参数校验。无法读取时明确报错，用户可通过原同步流程保存正确结构。

个人中心各页采用浅灰背景与统一白色设置面板，左侧导航以内部分隔线连接右侧内容，字段使用细线和留白分组，不再逐项独立成卡片。身份信息仅在资料区展示。点击头像直接选择图片，移除头像收在更多菜单内并确认；不再单列更换/移除按钮。资产数量来自现有接口，历史会话页仍管理聊天记录，不展示未实现的登录设备信息。

知识库点击上传先打开统一弹窗，虚线框内展示选择入口、待上传文件、上传进度和结果；选择、拖入或粘贴后先加入队列，再点击上传。粘贴文本生成 TXT。已上传文件留在虚线框内，失败项可重试且不重复上传成功项；上传完成不等于解析完成，解析进度仍在文档列表查看。粘贴仅在上传区域处理，不劫持页面其他输入。

工具与 MCP 工具统一保存在工具表，技能保存在独立技能表；草稿和不可用资源仍保留以供管理。工具、MCP 与技能仅对创建者可见，管理员权限不扩大这些资源的归属范围，选择器同样遵循此规则。

斜杠菜单按当前状态生成个人资源命令，每次重新展开时向后端刷新。工具需已批准、生命周期就绪、配置有效且权限为允许或每次确认；MCP 工具还须关联同用户已接入且未禁用的服务器。一次临时连接测试失败不取消已有命令。技能须已发布且正式文件存在、非空。禁止、取消批准、取消发布或删除后，命令不可用。普通工具、MCP 工具和技能的命令编码按类型及资源 ID 区分，同名资源不会混淆。

选择资源命令只回填输入框，发送时后端再次验证归属、状态及当前智能体的能力绑定，再通过原有工具调用或技能加载流程处理；工具审批仍生效。基础对话或未绑定对应能力的智能体会明确提示选择已启用该能力的智能体。测试接口不承担正式命令执行。

快捷菜单中的工具和技能仅显示完整名称，名称可换行，不展示内部命令编码或编号；系统动作保留斜杠命令格式。描述在列表中截断，仅悬浮描述区域时通过气泡查看全文；名称、图标和其他行区域不触发气泡。

聊天选择器、路由与运行入口仅允许使用自己的智能体，避免通过他人的智能体间接调用其私有能力；智能体管理查看权限保持独立。重建运行时不会连接或重新启用已禁用的 MCP。当前智能体同时绑定多个同名工具时，资源命令明确拒绝执行，需改名或仅保留一个，防止工具注册名覆盖造成误调用。

工具和 MCP 工具共用测试弹窗：说明区固定高度并可内部滚动，参数区不被长说明挤压。参数模板优先使用 schema 中的默认值、示例和枚举，并保留数字、布尔等类型。参数 JSON 顶层必须是对象。

“AI 智能填入”只根据当前工具已保存的名称、说明与 schema 调用配置模型生成参数，不执行工具、不读取工具密钥。生成期间锁定参数和运行入口；成功后填入可编辑 JSON，仍须点击运行测试。生成失败显示错误并保留原参数，关闭或切换工具后旧结果不会覆盖新输入。执行失败按错误显示，并保留脱敏返回内容以便排查。

测试控制接口始终使用 POST，实际目标调用沿用工具保存的 HTTP 方法及参数映射；MCP 通过工具协议调用。可选 confirmed 未提供时视为未确认，不再因基础布尔类型 JSON 解析失败而直接返回 400，需确认工具的审批机制保持生效。

### 工作空间权限与修复边界

工作空间操作同时校验模块权限与资源归属：隐藏菜单不等于后端放行。仅有聊天权限时仍可获取可用智能体摘要；管理详情、草稿和资源修改按对应权限拒绝。智能体编辑页的能力选择只返回目标所有者可选资源，不授予工具、技能或知识库的管理权。

草稿保存只确认已提交的编辑版本，保存期间继续输入会等待下一次提交；保存失败不会发布旧快照。每份草稿只生成一个正式结果，发布中的准备记录不能被选择或运行，成功后草稿不再显示为未完成。发布状态查询失败时保留草稿并提供重试。

技能名称与目录限制在受管范围内，拒绝越界路径及不安全链接。ZIP解压上限为单条16 MiB、总计64 MiB、512个条目和64个技能；目录和忽略项也计入读取限制。技能包写入失败会回滚整批数据库记录并清理本批临时文件。

MCP变更确认核对服务、所有者、工具与刷新版本，非法选择不产生部分更新。旧会话中的新调用也受删除、禁用与解绑限制；权限从允许改为需确认时，旧调用会被阻止，下一轮按最新配置确认。已经发送到远端的操作不承诺能够撤销。

知识库重启后直接重新打开已有向量索引，不要求重传文件。文档页同时跟踪当前页解析状态与全库解析数量，避免统计瞬间不同步时永久停止刷新。

发布中断恢复面向单节点启动：更新服务前停止接收发布请求，不混跑新旧节点。历史异常技能路径、多个成功发布目标等情况保留证据并拒绝自动处理；修复不会自动删除用户未知目录或重复智能体。

在 `/tools` 页面集中管理 HTTP 工具与 MCP 服务。工具目录支持自动解析执行入口、保存前连通性探针检查、原地配置编辑、受控单次测试调用、差异比对与删除影响分析。

工具和 MCP 列表输入关键词后，点击「搜索」或按回车才应用筛选；清空关键词并搜索可恢复全部结果。导入工具弹窗使用简短字段与操作文案；接入 MCP 输入框提供配置示例，连接前请替换示例地址。列表保留连接地址、已批准工具数量与具体工具名，省略名称装饰图标及重复的 HTTP 协议标记。

- **连接检查与测试调用的区别**：
  - **保存前连接检查**：导入或编辑工具时由后端自动执行轻量级连通性探测（验证主机与 TLS 握手、服务基地址与 HEAD/OPTIONS 连通性，MCP 服务执行初始化握手与工具列举），确保执行入口存在且服务可达。连接检查**不代表业务参数合法或接口功能验证通过**，且**绝对不会自动发起带有业务副作用的 POST/PUT/DELETE 写操作**。
  - **业务测试调用**：在测试面板中由用户主动填写真实业务参数发起单次调用，展示真实 HTTP 状态、响应正文、执行耗时与有界分页展示；对涉及写操作的测试需要用户二次明确确认。测试行为不代表已保存新配置，也不会自动提升或绕过工具权限。
- **OpenAPI 与格式支持边界**：
  - 支持 OpenAPI 3.0 与 3.1（JSON 与 YAML 格式）以及独立 JSON Schema；支持从文档根级、路径级或操作级 `servers` 自动提取服务基地址，允许输入框地址留空；支持常见 path/query/header/cookie 参数映射与 Bearer / API Key / Basic 认证。
  - **不承诺支持全量 OpenAPI 高级规范**：不支持 OpenAPI 2.0 (Swagger)、外部 `$ref` 网络抓取、循环递归嵌套模型、回调/Webhook 作为可执行操作、以及复杂的 OAuth2 动态认证流；遇到不支持项时明确返回诊断错误，不静默伪装成可用。
- **MCP 变化感知与原子确认**：
  - MCP 服务通过「检查更新」主动拉取远端工具定义，比对生成新增、同名结构变更、移除三类差异快照并持久化；确认前移除的工具立即标记不可调用。用户在差异对话框中核验后，通过原子事务批量应用所选变更，保留原工具 ID、权限与既有智能体关联。
- **删除影响分析与安全防护**：
  - 删除工具或 MCP 服务前，系统自动查询关联的正式智能体与下游工具集合；用户确认后在同一事务内完成依赖解绑与记录清理，即时阻断运行上下文对已删除工具的新调用。


## 模型设置与会话选模

模型接入和编辑保留当前标签页的未保存草稿，包括供应商、模型 ID、地址、显示名称及临时输入的密钥。刷新后重新打开同一接入/编辑表单即可恢复；保存成功或明确放弃修改后清除，不恢复先前测试结果。草稿不写入 localStorage，退出登录时清除。

新增模型初始不预选服务商或填入地址；抽屉打开时不自动展开任何候选列表。配置已有模型保留原值。用户主动进入服务商或模型ID输入框后才展示选项。

模型设置分为对话模型与向量模型，默认状态直接标记在列表行，不再显示顶部大卡片。列表展示名称、模型ID、服务商、API地址、密钥状态、最近测试结果与时间；向量列表另显示真实向量维度。列表关键词仍在点击搜索或回车后应用，最近测试不代表实时在线状态。

点击「接入模型」打开右侧抽屉，模型信息和连接设置分组呈现，地址与密钥直接展开，测试、取消和保存固定在底部。服务商内置21个预设，包括OpenAI、Anthropic、百炼、DeepSeek、智谱GLM、Kimi、硅基流动、OpenRouter、MiniMax、阶跃星辰、Groq等以及部分国际站和自定义服务。智谱普通API、智谱Coding及Z.ai Coding分别显示，避免混用套餐地址。选择后带入对应地址；预设是连接建议，不承诺账号可用性。向量入口仅显示已核实的兼容预设；Anthropic对话仍使用原生Messages协议。

「获取模型」仅请求当前连接，成功时显示实际返回数量，空列表和请求失败分别提示；不会通过DeepSeek官方接口获取其他厂商的GLM模型。接口不支持枚举时仍可使用内置建议或手动填写ID，保存时以真实连接测试为准。

服务商和模型ID均支持聚焦展开、即时搜索、方向键及回车选择；模型ID仍可手动填写。搜索约200ms防抖，关键词发后端匹配，前端不取全量后自行筛选。输入关键词不会请求厂商接口；「获取模型」才主动请求厂商，结果在后端按连接及凭据隔离、限量缓存5分钟，后续搜索在缓存中匹配，未获取时显示内置建议。获取失败保留模型ID与配置，仍可手动输入。已有配置保持原协议和密钥保留机制。

「测试连接」只验证当前草稿，不保存或切换默认模型。连接参数修改后清除旧测试结果。保存时服务端验证当前配置，失败保留输入与原配置；新增默认不激活，只有勾选「设为默认」才改变系统默认。测试会发送少量真实请求，可能产生供应商调用费用。

配置已有模型时保留模型标识，密钥仅显示已配置；点击「更换密钥」才填写新值。关闭有未保存修改的抽屉时需确认放弃。更多菜单提供测试、设为默认及删除；切换默认与删除均有确认及失败反馈，默认或已被会话引用的模型不可直接删除。

设置页管理系统默认模型；对话框内选择只保存到当前会话。新建会话创建时绑定当时的系统默认模型，之后修改默认模型不会改变已有会话。运行开始固定所用模型、容量与使用量归属。选模沿用现有管理权限与会话所有权检查。

向量模型已有索引数据时，阻止直接更换模型或修改生效端点，即使向量维度相同也不能视为兼容；提示需要处理并重建索引，不静默切换。后端重启时自动应用模型显示名称、最近测试记录和会话选模的增量字段。


## 管理列表格式

用户与角色页参考芋道布局：搜索卡片内使用紧凑横排条件，搜索/清除提交后才查询后端；新建按钮位于下方列表工具栏。用户使用“账号”，角色使用“角色标识”，列表只显示真实字段，角色不再显示人数。两页行操作使用共享文字变体“编辑、删除、更多”，用户更多项包含分配角色、重置密码和启停，角色更多项提供菜单权限。下拉面板与触发框等宽对齐。

用户搜索支持账号、昵称、状态、角色和创建时间；角色搜索支持名称、角色标识、状态和创建时间。文本提示统一“输入字段名”，查询按钮紫色、清除按钮白色。创建时间使用同一个组合范围框，弹层提供今天、最近 7 天、最近 30 天、昨天、本周、本月、上周，日历和时分秒列。确认范围只更新草稿，查询或回车提交后才执行后端昵称/时间过滤及分页；清除重置全部条件并返回第一页。日期时间按浏览器本地时区解释，包含所选结束秒；只填结束日期时包含结束当天。

用户编辑、角色编辑及重置密码的标签和输入文字使用更深灰色。菜单权限默认折叠页面分组，展开/收起不改变选择与半选状态，保留只读和管理员管理入口保护；勾选与确认使用较浅紫色。

权限树统一预留展开箭头的位置，子菜单与按钮权限逐级向内缩进，同层节点的复选框保持对齐。

新建用户和分配角色使用共享多选下拉框，回显已有角色并支持清除；在下拉菜单内连续勾选后点击确认保存，取消不修改授权。

分配角色的搜索直接集成在角色下拉面板内，仅展开时显示，不在弹窗中单列搜索字段。按名称输入约 200ms 后由后端匹配，搜索不清除已选角色；加载、无结果和失败重试分别展示。

用户编号和角色编号分别从 1 起，由数据库生成并持久保存；搜索、翻页或删除记录后不会重新编号。内部关联继续使用原标识，已有角色分配、会话和权限不受编号迁移影响。

编辑用户可修改账号、昵称和备注；账号必须非空且唯一，原密码及角色分配保持。更名后使用新账号和原密码登录，保存冲突时保留输入供修改。角色操作从左到右固定为“编辑、删除、更多”：编辑在同一弹窗保存角色名称、角色标识、排序、角色状态；“更多”仅提供不带图标的“菜单权限”。Admin 角色可编辑名称、标识、排序和菜单权限，删除、停用仍禁止；其他内置角色保持原保护。

内置管理员更名后，启动引导依据已有内置身份确认初始化，不会按旧配置再创建一个管理员或恢复旧引导密码。

角色授权从后端加载页面和按钮权限树，支持全选、半选，失败保留勾选；重新打开读取服务端最新值。Admin 的菜单权限可修改，权限管理入口必须保留，后续启动不会覆盖已保存的权限。旧管理权限保留原有范围，按钮权限不会自动扩大资源归属；分配角色需授权权限，修改内置/超级管理员需权限管理授权。内置 admin 账号和内置角色禁止停用或删除，最后一个超级管理员也不能被解除。

模型列表点击“复制配置”会直接创建一条持久化副本，包含原连接、密钥和向量/上下文配置，新增名称带“副本”，不设为默认，也不额外调用厂商。复制后刷新列表；超过一页时定位到新增记录所在末页。响应继续掩码，明文密钥仅在后端复制，不进入页面或剪贴板。更改地址后切为自定义并要求重新填写密钥。服务商选择由后端即时搜索，对话与向量模型共用同一服务商目录。向量模型获取和缓存搜索保留厂商返回的全部 ID，不按名称或能力标记过滤，支持火山方舟等不含 embedding 字样的部署 ID；是否可用于向量通过保存前的真实向量响应和维度校验确认，目录展示不等于厂商具备该能力。列表名称与下方别名展示保持原样，向量维度表头与数值不换行。

智能体列表增加启用/停用状态标签，正式智能体提供编辑、启用/停用和删除三个操作；草稿保留继续配置和删除，不提供启停。删除沿用确认弹窗。状态独立保存，历史智能体默认启用；停用项仍可管理，但不出现在聊天候选中，路由及运行入口拒绝新执行，重启和工具配置刷新不会重新启用。停用不强制中止已经开始的执行，已有连接按原租约机制退役。重新启用会重建运行时，重建失败时恢复原状态并显示错误。

左下角账号区域优先显示昵称，昵称为空或只有空白时显示账号；修改本人昵称成功后即时更新。

工具/MCP、模型、技能、知识库、文档、用户和角色的表格沿用同一套列表组件。统一白底细边框、浅色表头、行间距和首尾留白；操作列靠右、不折行，窄屏在表格区域横向滚动，分页位于表格底部。

行操作采用与工具页一致的小尺寸描边按钮：文字或图标加文字；删除用红色图标按钮并提供名称提示。常用操作直接展示，低频操作放在「更多操作」，危险操作排最后。没有权限的操作隐藏，暂不可用的操作禁用，执行中显示等待状态并阻止该行重复操作；已有业务确认弹窗保持不变。

标准搜索在点击搜索或回车后才生效，筛选和新增入口位于表格上方。加载、失败重试、暂无数据和搜索无结果使用统一区域；即使当前页没有记录，也保留表头和分页返回入口。

开发时使用 `DataTable` 的 `columns` 和 `actions` 配置业务内容，操作配置只描述 `id`、`label`、`icon`、`iconOnly`、`tone`、`hidden`、`disabled`、`loading`、`overflow` 和 `onClick`。特殊业务行可继续使用 `renderRow`，但操作栏必须复用 `TableActions`。不为不同页面另造表格框架或操作按钮样式。

智能体能力选择器（工具、技能、知识库，含创建页的「高级能力配置」）是同一套组件的另一类用法：勾选列放在名称列，行内容仍由业务提供，加载、失败重试、空结果与分页统一由列表承载。选择器必须复用 `DataTable` 与 `TableToolbar`，不得自建搜索栏、列表容器或分页。

弹窗统一用标题区、内容区与底部操作区三段，不使用上下两条横线分隔，靠间距与留白分区；底部按钮吸底由组件承担，页面不再自写操作区分隔样式。


智能体管理首次进入的总览复用标准 DataTable，提供名称、功能说明、类型和操作表头，加载和空结果时仍保留表头。编辑与继续配置使用统一32px纯文字操作按钮。桌面保留左侧导航，窄屏总览显示标准列表与搜索；详情编辑及未保存保护沿用现有流程。所有列表中的「编辑」固定为纯文字，不带图标。


知识库列表去掉顶部标题与副标题、名称旁装饰图标和行操作图标，保留纯文字操作；知识库与技能列表统一使用 TableToolbar。输入关键词只更新草稿，点击搜索或回车才应用并回到第一页；提交空关键词恢复全部结果，权限和状态筛选保持原逻辑。无匹配结果提供清除搜索/筛选入口。

## 管理列表按需加载

智能体、工具/MCP、模型、技能、知识库、文档、用户和角色列表均使用服务端分页，首次默认取10条，每页最多100条。后端先按权限、关键词及筛选条件查询，再返回当前页和准确总数，不再一次加载整个主列表后由浏览器分页。

点击搜索或回车提交关键词，重复搜索也会重新查询；翻页、调整每页条数、状态/权限/供应商等筛选都会请求后端。搜索和筛选从第一页开始，后续翻页保留已提交条件。输入框内尚未提交的文字不会影响当前结果。提示统一精简为「搜索智能体」「搜索工具」「搜索知识库」「搜索技能」等对象名称。

智能体总览由后端统一合并正式智能体与未完成草稿后排序分页，草稿可按用途搜索。知识库详情不附带全部文档，文档单独按页加载；解析期间仅刷新当前页或轻量摘要，完成后同步就绪数量。模型默认摘要独立于搜索结果保留。能力选择器同样走分页接口，额外带上 `purpose=selection` 与所属智能体或草稿，按被编辑对象的所有者取清单，只需智能体管理权限，首次 10 条、可切换 10/20/50；不带分页参数的旧数组接口保留兼容，页面不再调用。

## 知识库编辑工作台

页签精简为「文档 / 检索测试 / 设置」，沿用现有组件。文档页只保留搜索、状态筛选、上传和分页列表；选好文件后立即上传处理，也可拖入或粘贴。空列表只展示一个上传入口。文件不加装饰图标，处理失败可聚焦问号查看原因并直接重试。

检索测试只有一个问题输入框，点击测试或回车执行；没有可用文档时可直接选文件上传，不必先切换页签。结果只显示来源、原始相似度、片段和复制。相似度不代表答案准确率，相关说明放在可悬浮或键盘聚焦的问号中；复制成功后才提示已复制。

设置默认显示通用、问答、长文、自定义方案选择，高级参数按需展开。片段长度、重叠长度、返回条数和相似度阈值使用数字输入及问号帮助。保存失败保留输入；成功原位提示已保存。分块调整只用于新上传或重新处理的文档，不自动重建已有文档，保存后明确提示需要重新处理。

## 个人设置自助接口

用户从用户菜单的「个人设置」进入，应用侧边栏始终保留；主内容区复用Page、Card、Button和表单组件组成宽版工作区，包含资料、安全、偏好、我的资源和会话五个分区。顶部只保留左箭头返回，页面不显示重复大标题/副标题；右卡固定在可用视口内，内容独立滚动，设置项之间保留浅色分隔线。「关于」分区已移除，旧地址回到资料页。页面沿用1440px最大内容容器，设置导航占192–224px，其余宽度交给当前分区；窄屏字段上下排列并使用分区下拉。所有`/api/me/*`请求必须登录，只操作本人账号；会话删除沿用chat.use权限。现有`/api/auth/me`返回昵称、头像信息和roleNames；账号来自用户管理的同一账号字段，角色显示角色管理中当前有效关联角色的名称，头像文件路径不返回客户端。

| 操作 | 接口 | 行为 |
| --- | --- | --- |
| 修改昵称 | `PUT /api/me/profile` | 去除首尾空白，最多40个字符，允许清空，不改变账号和管理员备注；页面通过右侧保存按钮或回车提交 |
| 修改密码 | `PUT /api/me/password` | 校验当前密码，新密码8–256字符；同事务更新密码并撤销其他登录，保留当前登录 |
| 退出其他设备 | `POST /api/me/sessions/revoke-others` | 保留当前登录，不影响其他账号 |
| 头像 | `POST /api/me/avatar`、`GET /api/me/avatar`、`DELETE /api/me/avatar` | 上传字段为file；PNG/JPEG/WebP，最多10 MiB、每边最多8192像素；替换清理旧文件，删除后恢复默认头像；页面不常驻限制文案 |
| 会话安全删除 | `DELETE /api/me/sessions/{sessionId}` | 仅本人且非运行中记录可删除；运行中返回409；批量按钮复用此入口并要求二次确认 |
| 个人偏好 | `GET /api/me/preferences`、`PUT /api/me/preferences` | Think、推理程度档位、默认模型、默认智能体；支持只更新部分字段，不改变全局或已有会话 |
| 本人资源 | `GET /api/me/overview` | 本人的智能体、技能、知识库、工具数量；无查看权限的项返回null；凭据只返回配置状态 |
| 版本信息 | `GET /api/me/about` | 应用名称与构建解析的后端版本 |

头像通过带Authorization的请求读取，不能把token放进图片URL。成功响应使用私有缓存并以Authorization区分缓存；PNG/JPEG使用ImageIO校验，WebP校验RIFF、帧头和尺寸，支持静态及动画，不宣称完整像素解码。

偏好未设置时为Think关闭、模型跟随系统、智能体自由模式，`initialized=false`。旧浏览器Think值迁移时使用`If-None-Match: *`条件写入；已有服务端偏好返回412，避免覆盖用户明确保存的值。普通编辑不带该条件。非当前聊天模型沿用现有模型选择的管理范围，智能体必须对本人可用。语言继续保存在浏览器，不在此接口同步。

凭据清单不包含密钥、密文或凭据引用。configured表示已有凭据引用或MCP环境/请求头配置，不代表远端认证已验证成功。会话列表与单项操作保留现有接口兼容，删除所有使用上表的安全删除入口。

权限概览为只读折叠状态树：按模块显示已授权数量，展开可查看权限名称与已授权状态。会话页的删除所有操作覆盖当前确认清单，先展示数量再确认；不删除确认后新建的会话。有运行中会话会提示停止，部分失败会刷新实际剩余记录，可继续重试。

前端默认项只作用于新会话：Think、默认模型和默认智能体在创建前按当前账号可用范围校验，显式单次选择优先；模型绑定失败会清理已创建的空会话。头像通过鉴权请求读取为本地预览，不把token放入图片URL。设置页的语言继续沿用浏览器偏好，不落库。
