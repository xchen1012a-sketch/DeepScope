### 阶段四设计要点（用户逐轮纠正后的最终定义，勿再改）

1. **主智能体是"队伍"**：技术参谋是内置第一位，用户可新建更多主智能体，每位都是独立对话服务者。
2. **子智能体挂在主智能体下面**，增删改发生在所属主智能体层级。
3. **消息双模式**：新建会话不选智能体 = 自由模式（每条消息先由小模型 route 一次选派哪位主智能体，结果落时间线 `agent_route` 事件）；选了 = 锁定模式（整场绑定该智能体，不走 route）。
4. **可见性/权限**：内置智能体所有人可见、仅 Admin 可改；个人智能体仅创建者 + 管理员可见可改。
5. **新建起点**：空白创建 或 从现有智能体复制二次改造（复制时预填"{源名} 副本"）。
6. **F08 提案协议**：模型用 report_proposal 工具发子智能体定义草稿 → awaiting_visitor 状态 → 前端提案卡片（草稿可编辑）→ 用户批准后写 `subagents/{slug}.md`，下一轮即可派发（框架中间件逐轮重载，无需重启）。内置智能体提案仅 Admin 可批准落盘；自由模式会话不允许提案。
