# 对话入口、执行体验与恢复实施计划

日期：2026-10-16（Asia/Shanghai）。用户已授权先整理计划，再顺序执行。复用现有 React/Radix/TanStack Query、AG-UI 与 Harness；保留混合工作区，不启动浏览器，不启停用户后端。

## 范围与执行顺序

### 1. 新建入口和消息操作

- 首页标题按 Asia/Shanghai 时区：00–05“夜深了”、06–08“早上好”、09–11“上午好”、12–13“中午好”、14–17“下午好”、18–23“晚上好”；后接当前昵称，空昵称回退账号。定时刷新问候，避免页面长时间打开后过时。
- 所有聊天输入状态统一“与 DeepScope 协作”，包括新建、执行中、等待回复；去掉首页输入下方重复显示的“备好的问题”预览卡，真实追问卡不删除。
- Markdown fenced code 块右上角常驻复制；用户气泡下方复制与真实发送时间同一行，悬浮或键盘聚焦显示，触屏可用。时间无数据时不伪造。复制失败有可重试反馈。
- 文件：ChatPage、ComposerDock、ConversationPanel、Markdown，必要时共享复制按钮与问候函数；同步 EN/ZH 词条与组件行为测试。

### 2. 执行侧栏和模型选择

- 侧栏入口只保留显示/隐藏图标及无障碍名称，去掉可见“会话执行过程”文字；侧栏右上角关闭叉号移除，仍可用入口和 Escape 关闭。
- 增加左边界拖动条，支持鼠标/触控及键盘左右调宽，有合理最小/最大尺寸，窄屏不超出视口，不阻挡正文操作。
- 移除“跟随系统默认”候选；新对话显示并绑定当前默认模型，新建后不因默认模型改变而静默切换；历史未指定模型的记录继续兼容。
- 文件：ProcessDrawer、ConversationPanel、ModelPicker、SessionModelController/SessionStore（如默认绑定需后端落点），现有模型和侧栏测试。

### 3. 斜杠与标题同步

- 新建输入复用同一斜杠菜单逻辑与真实命令目录；执行中输入 / 仍能展开选择，压缩/清空等互斥动作明确不可在运行中执行，普通命令沿用排队/下一轮语义。
- 最近会话有界刷新未命名/活跃会话，详情更新同步列表缓存；命名落库后无需切页或等待执行结束才显示。停止无必要轮询，避免取全量过程。
- 文件：ChatPage、ComposerDock、SlashCommandMenu、SessionNav、useAdvisorConversation；覆盖输入法、箭头/回车、执行中选择和标题晚到测试。

### 4. 手动与自动压缩

- 去掉手动压缩的消息数量/上下文大小门槛；有持久上下文即可尝试强制压缩，空会话无内容不伪造结果；运行互斥和失败保留原上下文不变。
- 自动压缩显式阈值 800,000 tokens；模型窗口不足 800K 时优先保留已有模型容量保护，不能等超出实际窗口才处理。主智能体及基础对话使用同一策略；不改变 SDK 全局默认。
- 文件：SessionCompactionService、AgentProvisioner、BasicChatRuntime 与项目现有 CompactionConfig。覆盖短上下文、800K配置、模型小窗口安全边界。

### 5. 刷新/短暂断网不中断服务端运行

- 应用配置 agentscope.agui.interrupt-on-disconnect=false，使用框架现有独立执行；显式停止接口仍中断，超时仍生效，不把断网当用户停止。
- 页面恢复时依据已授权详情接口的 runtime 状态和持久过程轮询接管，运行/收尾中维持执行态、持续更新；完成停止轮询。前端不能重发原问题来假装恢复，不重复创建消息或任务。
- 流短暂断开后先核对服务端运行状态，不把仍运行的任务标为失败；只在确认终态失败时显示失败。保持原事件去重与原始执行 ID，终态不回退。
- 优先改应用配置与应用侧恢复，不改 SDK 公共契约；若发现必须调整框架取消语义，先升级分级和计划，完成可审查的设计再处理。

## 验证与交付

- 每阶段先写可观察行为测试，确认缺口，再最小实现；样式微调不写机械镜像测试。
- 前端相关测试→全量 Vitest、Lint、TypeScript/Vite Build；后端会话/模型/压缩/配置集成与 Spotless，整模块测试使用隔离 pgvector 测试库。
- 对恢复链路用真实可控本地流测试验证“断开不停止、刷新取回、主动停止仍有效”；不使用真实厂商密钥，不声称未测网络环境已验证。
- 更新 docs/v2 EN/ZH；只读审查重点是取消语义、重复发送、默认模型固定、消息/时间保留、上下文安全、复制失败、拖动与焦点。
- 完成记录注明通过、跳过与运行部署状态；不提交/推送，不重启后端。各阶段可独立回退，保留已有数据库与历史事件结构，新增字段只做兼容补充。
