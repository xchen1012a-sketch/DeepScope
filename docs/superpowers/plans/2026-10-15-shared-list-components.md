# 通用列表与操作栏统一计划

用户已指定沿用工具与 MCP 列表的按钮式操作栏，并要求在统一组件内扩展功能、定义格式。本次为中级纯前端跨 feature 改动；基于现有 DataTable/Pagination/Button/AppSelect/Radix，不引入依赖。

## 组件约定

- DataTable 统一容器、浅色表头、行间距、首尾边距、悬停、操作列右对齐和内容不折行。现有列 cell 扩展保留，特殊行 renderRow 保留。
- 增加 actions 行操作配置，集中生成操作列；业务页提供名称、图标、是否显示/禁用、执行中状态、点击行为、危险/提醒语义及是否放入更多菜单，不再自己写操作按钮样式。
- TableActions：常用操作统一32px高、12px字、白底细边框圆角小按钮，允许纯文字或图标+文字；删除为最后的红色图标按钮并有可访问名称与提示。更多入口同规格，无权操作隐藏，暂不可用禁用；执行中显示spinner并阻止重复触发。
- 不按数量自动折叠以免改动页面已有操作路径；较少用操作由页面显式标记overflow；常用通常不超过3项，危险操作始终末尾。
- TableToolbar：搜索表单和筛选槽位，输入不提交、按钮/回车才搜索；查询状态仍由页面管理，不额外引入数据缓存或分页机制。
- 加载、错误/重试、无数据、无搜索结果和分页由列表统一承载；有空结果时保留表头和可返回前页的分页，避免分页入口消失。业务传文案与动作。
- 搜索/新增与行操作区分：新增在页面工具栏，行按钮只作用于当前记录。

## 迁移范围

工具/MCP、模型、技能、知识库及文档、用户/角色：复用操作栏，统一DataTable列和分页。保留既有权限、确认弹窗、请求行为、搜索业务和业务列内容。卡片/智能体分栏等非表格布局不强制改成表格。
