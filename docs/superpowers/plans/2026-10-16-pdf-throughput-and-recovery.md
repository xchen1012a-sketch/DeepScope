# PDF 吞吐与恢复实施方案

用户已批准按四步实施。基于当前 DocumentIngest、KnowledgeEmbeddingModel、PdfContent、PdfParser 和原子发布链路，保留混合工作区既有改动；不新增外部服务或框架，不假定兼容代理支持批量嵌入。

## 1. 受控向量并发

官方火山多模态 input 数组并不等于独立文本批处理；当前 coding 代理的批能力未确认。因此先使用单条兼容请求，所有文档共享一个有界执行池，默认最多3个请求。每篇只保持有限在途任务，按原片段顺序汇总，任一错误取消其余在途请求，不发布半成品。线程空闲60秒退出、服务关闭取消并清理。配置 embedding-workers 范围1—8。

## 2. 合并短片段

同一物理页、同一标题区内合并相邻普通段落/列表/标题到现有 chunkSize；不跨页、不跨新标题、不把表格或图片解释混入正文。Source 兼容增加 spans（块ID/类型/坐标），保留原块定位与单一主来源字段。合并后 ID 延用首块+切片序号，原始页面块不改；检索预览可高亮多个来源区域。

## 3. 有限页级降级

视觉请求与普通向量请求使用独立预算：视觉单次45秒、总90秒、最多1次瞬态重试；向量沿用25秒/总60秒/最多2次。解析并发默认2，由共享视觉读器限制。日志记录安全重试类别及阶段耗时，不输出正文/凭据。

整页遇到超时/截断/格式失败时，最多进行一次两区解析；按PDF声明旋转校正分区图像，仅在页面中部附近找到连续空白分隔带才裁切（双栏优先竖分，否则横分），不强行切断表格/文字。两区必须全部通过现有完整性校验，位置映射回原物理页；任一区失败、无安全分隔或全部空白但原页非空，整页仍失败。鉴权/限流/取消不触发分区补发，分区不递归。已成功页结构契约不变，保留原解析签名版本以复用既有成功页；新的切片/向量版本通过独立指纹管理。

## 4. 断点及进度

新内部 embedding checkpoint 表：文档外键、模型/文件/解析及切片版本指纹、片段ID、内容及来源摘要、向量。真实模型身份包含端点配置、模型与维度摘要；无法识别身份的自定义模型不复用。每片成功后保存，重试只补未完成片段；配置或内容变化不复用。当前模型变化时拒绝发布。原子发布成功的同一事务清理内部checkpoint，失败保留；文档删除级联清理。检索只读原有已发布表。

文档列表响应兼容新增 embeddedChunks/totalChunks 字段，显示“已向量化x/y”；解析与向量化分别记录开始/完成耗时、总数、复用数及安全错误类型。完整发布、旧版本保留和文档任务总预算不变。

## 定向验收

有界并发/顺序/取消；短片段合并及表格边界/多来源；安全空白裁切、坐标映射、分区失败及取消；checkpoint失败后复用/身份变化失效、删除级联及原子发布；进度字段与前端展示。每步一次足够的定向测试，失败时精确重跑；最终受影响链路、构建及格式检查，不重复全仓、不起浏览器。实施后只读审查一次。更新本地后端前确认无活动任务，不自动重新解析用户文件。
