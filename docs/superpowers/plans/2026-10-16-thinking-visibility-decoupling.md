# 思考过程展示与模型思考解耦

个人中心现有 thinkEnabled 仅作为思考文本的展示偏好，保留 API 和存储兼容；模型选择器的 thinking 和 reasoningEffort 继续作为实际请求参数。ChatPage、ConversationPanel 不再用账号展示偏好初始化模型思考开关。

隐藏在展示投影层处理：过滤历史/有序过程中的 thinking 块，隐藏实时 ThinkingLine；最终回答及工具行为保持原链路。原事件和流式数据保留，切回展示时可立即恢复，无需重跑模型。过程侧栏使用同一过滤后的投影。

验证新建与已有会话：账号展示关闭时，模型思考仍保持已选择状态及程度；历史/流式思考文本不显示，最终回答仍显示；修改展示偏好可即时恢复/隐藏。仅运行受影响前端定向测试、build/局部 lint，不启动浏览器、不修改后端。
