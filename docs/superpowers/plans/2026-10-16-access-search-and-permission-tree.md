# 用户/角色搜索与授权交互调整

本轮按用户明确要求直接实现，中级应用内变更。

状态：已完成；证据见 `technical-advisor-app/docs/access-search-and-permission-tree-results-2026-10-16.md`。

## 行为与契约

- 用户分页增加 nickname 模糊匹配、createdFrom / createdBefore 毫秒时间边界；角色分页增加同样的时间边界。条件在 SQL COUNT 与 LIMIT 前应用，沿用参数化查询与原权限校验。
- 日期时间使用浏览器本地时区：开始时间包含，结束秒包含（传入后端时加一秒为排除边界）；按整天选择时包含结束当天。可只填一端；非法时间、倒置范围返回 400。
- 输入与日期为草稿，点击查询或回车才提交；清除清空全部草稿和生效条件并回到第一页。提示统一“输入{{字段}}”，日期为“开始日期/结束日期”，筛选空值显示“全部”。
- 按用户补充的芋道截图，采用单个组合范围框，弹层内包含今天、最近 7 天、最近 30 天、昨天、本周、本月、上周，日历和时分秒列，确认后更新查询草稿。项目没有日历组件，接入经包元数据确认兼容 React 18 的 react-day-picker 10.0.2，组合现有 Radix Popover、Input、Button，避免自建日历键盘与日期导航。
- 标准标签搜索模式的查询按钮使用现有紫色主按钮，清除保留白色描边。
- 用户编辑、角色编辑及重置密码加深字段标签和输入文字。菜单权限默认折叠页面分组，支持独立展开/收起，折叠不改变勾选，保留半选与锁定权限。紫色勾选和确认按钮调浅。
