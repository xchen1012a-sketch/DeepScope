# 新建会话布局、上下文与导航一致性实施计划

日期：2026-10-16。用户授权执行七项调整；已确认压缩问题发生在有记录的具体历史对话。遵循 AGENTS.md 与既有 React/Radix/TanStack Query/Harness 模式，保留混合工作区，不启停用户后端、不提交、不启动浏览器。

## 1. 新建页与复制操作

- 首页问候与输入区增加约 32px 间距，输入区拓宽至现有会话输入宽度，并提高空白页输入高度。
- 在现有 ComposerDock 增加 welcome 展示变体，复用全部附件、斜杠、模型与发送逻辑；普通会话输入保持紧凑。
- CopyTextButton 只显示图标，成功切换对勾、失败保留可重试反馈；名称通过 aria-label 和悬停提示表达。
- 覆盖现有输入、滚轮及复制回归，样式不新增机械测试。

## 2. 历史上下文压缩

- 已定位：Harness 默认启用原生 SessionLogStore，但手动压缩只读取旧 AgentStateStore。
- 通过现有 SessionLogStore 和 DurableSession 的 writer/workingState/checkpointNow 读取实际上下文并持久化摘要，不直接写日志文件、不新建存储协议。
- 保持会话所有权、运行互斥和模型选择；旧状态路径保留兼容，空上下文不伪造内容，模型失败不写摘要。
- 真实 Harness + 隔离原生日志测试复现旧状态为空但历史存在的情况，验证成功后从日志重新读取到摘要、原聊天展示记录保留；覆盖失败、空会话及旧状态。
- 仅应用层适配既有公共接口，不修改 SDK 公共契约或取消语义；REST 路径、请求响应及错误码兼容。

## 3. 名称同步

- 根因是侧栏会话列表与主会话详情拥有独立缓存/轮询；数据库中名称本身已是单一字段，新增数据库事务不能解决两处展示时序。
- 抽取现有会话列表查询策略并由两处复用同一 query key；主标题与侧栏优先读取同一份名称，避免重复发起独立命名请求。
- 保留未命名会话有界刷新、运行态与手动重命名；测试列表刷新后两处同时采用新名称，旧详情不能覆盖新名称。

## 4. 左侧栏布局

- 使用固定高度 flex 布局，移除侧栏外层与设置区的滚动容器，只有近期会话占剩余空间并滚动。
- 使用已安装 Radix ScrollArea 的 scroll 模式，滚动时显示细滚动条，停止后自动隐藏，不写第二套滚轮机制。
- 工作空间与设置改为可折叠分组，默认收起或打开当前路由所在组；两组互斥展开以节省空间。展开后使用已有 Input 搜索可见导航入口。
- 用户补充：折叠时隐藏搜索框，展开面板增加白底、浅灰细边框与轻阴影，与近期会话区分。
- 用户进一步明确：边框须包住标题及内容整个分组，工作空间标题与近期会话之间保留间距，设置同样处理。
- 导航搜索针对静态且已按权限过滤的菜单，不请求业务列表或扩大权限。保留权限管理子菜单、移动导航、紧凑模式、头像菜单与语言切换。
- 覆盖展开/收起、菜单搜索、无权限入口隐藏、折叠侧栏后的访问及导航。
