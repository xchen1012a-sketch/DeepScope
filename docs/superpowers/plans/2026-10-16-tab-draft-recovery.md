# 输入草稿回填实施计划

- 复用现有 React 状态模式，增加一个通用标签页草稿 hook，使用 sessionStorage，同步写入，避免防抖窗口内刷新丢字。
- 草稿按当前账号、页面/会话或模型 ID 隔离；存储损坏或不可用时继续正常输入。退出登录清理本应用标签页草稿。
- 新建页只保存文字；会话页按 sessionId 保存文字，已保存访客消息或进入已有运行队列后才清除。请求失败保留输入，异步回执不清除后来输入的新文字。不保存图片或附件。
- 模型接入/编辑保存文字、供应商及连接配置，含当前标签页临时密钥；不写入 localStorage，不恢复测试通过结果。保存成功和明确放弃修改后清理，普通刷新后重新进入相同表单恢复。
- 后端/API 不新增接口，仅在既有 send 流程增加消息接收回调。回填不自动发送消息、不自动保存配置。
- 测试覆盖重新挂载恢复、账号/会话隔离、清除、损坏存储、模型密钥仅临时保存、成功/失败发送清理。运行前端相关和全量测试、Lint、构建，更新双语文档；不启动浏览器或启停后端。
